Browser-based game experiences for Geek Cube Studio cartridges.

== Description ==

Geek Cube Studio connects WordPress-managed game metadata to a decoupled web
player. The initial project phase validates a mobile-first emulation pipeline
before catalog, cartridge and account features are introduced.

== Installation ==

1. Upload the `geek-cube-studio` directory to `/wp-content/plugins/`.
2. Activate Geek Cube Studio from the Plugins screen.
